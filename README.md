# Min e-handel

[Live Demo](https://e-handel-proj-a8q5.vercel.app/)

Fullstack e-commerce web application built with React and Express, using a cloud-hosted PostgreSQL database.

## Built With

- React
- Vite
- Javascript
- Node.js
- Express
- PostgreSQL
- Aiven
- REST API
- CSS

## About

An e-commerce application built with a React frontend and a Node.js/Express backend. The application uses a PostgreSQL database hosted on Aiven and communicates through a REST API.
